# Hand-drawn portfolio asset prompts

Generation mode: built-in `imagegen`, using the portfolio video frame as a style reference only.

## Project icon sprite sheet

Create a cohesive set of 12 small hand-drawn pictogram icons inspired by the reference portfolio website and Shu Weijia's projects. Arrange a focus timer with persimmon, tarot card, running headphones with voice waveform, CRM dashboard, fire-rescue drone, urban beehive, popsicle power bank, recyclable mask box, terracotta-warrior teacup, pencil and ruler, vintage computer, and friendly bird in a clean 4 × 3 grid. Use naive editorial pen drawing, slightly wobbly monoline, folk-stamp texture, warm cream, vermilion red and charcoal black. No text, letters, numbers or watermark. Generate on a flat green chroma-key background for later alpha removal.

## Side border rails

Create a matched pair of tall, narrow decorative border rails for the far left and right edges of a portfolio website. Stack small irregular vermilion stamp tiles containing original project-related pictograms such as the timer, star, headphones, dashboard, drone, beehive, power bank, pencil, bird, flower, cursor and abstract seal marks. Use naive hand-carved seal-print lines, uneven vermilion ink, charcoal outlines and cream highlights. Keep the wide center empty. No readable text or watermark. Generate on a flat green chroma-key background for later alpha removal.

## Container frame toolkit

Create four separate empty decorative content frames in a 2 × 2 grid: a rounded open-book panel with a vermilion rim and cream grid paper, a torn notebook-paper rectangle with stitched corners and tape tabs, a slightly tilted polaroid project card, and a ticket-shaped information card with perforated edges. Use warm paper, imperfect hand-drawn red borders, subtle grid lines and screen-print texture. Keep all interiors blank and spacious. No text, icons or watermark. Generate on a flat green chroma-key background for later alpha removal.
